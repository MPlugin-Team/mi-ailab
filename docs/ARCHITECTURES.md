# 🧠 Архитектуры в Mi-AiLab

Mi-AiLab поддерживает **4 типа нейросетей из коробки** + LoRA-дообучение готовых LLM.

## Сравнительная таблица

| Архитектура | Для чего | Параметры | Сложность тренировки |
|---|---|---|---|
| **MLP** (регрессия) | Табличные данные, числа | 1K-100M | Просто |
| **CNN** | Картинки, классификация | 100K-10M | Средне |
| **LSTM** | Генерация текста, последовательности | 100K-10M | Средне |
| **Mini-Transformer** | Текст с длинным контекстом | 100K-100M | Сложно |
| **LoRA на готовой LLM** | Свой ассистент за час | 1B-70B | Просто (но нужна VRAM) |

## 1. MLP (Multi-Layer Perceptron)

**Когда использовать:** табличные данные, регрессия, простая классификация.

**Архитектура:**
```
Вход (числа) → Linear(N) → ReLU → Linear(N) → ReLU → ... → Linear(1) → Выход
```

**В Mi-AiLab:**
- Режим `📊 Регрессия`
- Слайдеры: число слоёв (1-10), нейронов на слой (4-1024)
- 12 встроенных датасетов: iris, titanic, wine, math_*, california_housing

**Пример результата** (math_arithmetic, 50K параметров, 2600 эпох):
- Финальный loss: 0.00006
- Тест 34 × 20 = 680 → модель: 679.84 (ошибка 0.02%)

## 2. CNN (Convolutional Neural Network)

**Когда использовать:** классификация картинок.

**Архитектура (SimpleCNN):**
```
Conv2d(1→16, 3x3) → ReLU → MaxPool   # 28×28 → 14×14
Conv2d(16→32, 3x3) → ReLU → MaxPool  # 14×14 → 7×7
Flatten → Linear → ReLU → Linear → классы
```

**В Mi-AiLab:**
- Режим `🖼️ Картинки`
- Датасеты: MNIST (цифры), Fashion-MNIST (одежда)
- ~200K параметров достигают 98-99% точности

## 3. LSTM (Long Short-Term Memory)

**Когда использовать:** генерация текста char-level, последовательности.

**Архитектура:**
```
Embedding(vocab → 64) → LSTM(64 → 256, 2 слоя) → Linear(256 → vocab)
```

**В Mi-AiLab:**
- Режим `📝 Текст` → выбор архитектуры `LSTM`
- Токенайзер: char-level или BPE
- Live-генерация образца после каждой эпохи

**Пример** (Shakespeare, 1.4M параметров, 300 эпох):
```
HAMLET: To be by disgrace and unto my friend,
The day is sent for to conduct my woes;
```

## 4. Mini-Transformer (GPT-style)

**Когда использовать:** более качественная генерация текста, длинный контекст.

**Архитектура (как у GPT-2):**
```
token_embed + pos_embed
    ↓
[N × TransformerBlock(self-attention + FFN + residual + LayerNorm)]
    ↓
LayerNorm → linear(hidden → vocab)
```

**Преимущества над LSTM:**
- Параллельный по time-dim (быстрее на GPU)
- Длинный контекст без vanishing gradient
- Это что используется в GPT, Claude, Llama

**В Mi-AiLab:**
- Режим `📝 Текст` → архитектура `Mini-Transformer`
- Слайдеры: n_layer, n_head, n_embd

**Пример** (Tiny Shakespeare, 3.6M, 500 эпох):
```
KING RICHARD III: So, it is a good part of this deface,
Grand thousand men, so shall I send for favours?
```

## 5. LoRA Fine-Tuning (главное для serious ассистентов)

**Когда использовать:** хочешь реально работающего ассистента, а не «попугая».

**Принцип:**
- Берём готовую LLM (Qwen, Phi, Llama, Saiga)
- Замораживаем её веса
- Добавляем маленькие «адаптеры» (~1% параметров)
- Тренируем только их на твоих данных
- Получаем модель с твоей личностью на базе мощной модели

**В Mi-AiLab:**
- Режим `🤖 Дообучение`
- 6 моделей в каталоге: Qwen 0.5B/1.5B/3B, Phi-3 Mini, TinyLlama, Saiga 8B
- 4-bit квантизация для экономии VRAM (нужен `bitsandbytes`)

**Преимущество над from-scratch:**
- Модель **уже знает** русский, код, общие знания (натренировано на ПБ данных Meta/Alibaba)
- LoRA только подкручивает поведение под твой стиль
- Результат — **реальный** ассистент, отвечающий на любые вопросы

## Что выбрать для своей задачи

| Задача | Архитектура |
|---|---|
| Предсказание чисел из табличных данных | MLP |
| Классификация рукописных цифр | CNN |
| Стилевой генератор (под Шекспира, под код) | LSTM или Transformer |
| **Свой ChatGPT-подобный ассистент** | **LoRA на Qwen/Saiga** |
| Изучение основ ML с нуля | MLP → LSTM → Transformer (в этом порядке) |
